# EU4 Оптимизатор расположения крепостей

🇷🇺 Русский | [🇬🇧 English](README.md)

Небольшая настольная утилита для Windows, предназначенная для просмотра карты провинций **Europa Universalis IV** и её модов (включая глобальные моды вроде Анбеннар) и для планирования крепостей.

Программа загружает папку `map/` из игры, отображает её в нескольких режимах группировки, строит матрицу соседства сухопутных провинций и умеет решать задачу **минимального доминирующего множества**, чтобы подобрать минимальный набор крепостей, покрывающий все выбранные провинции.

> **Правовая оговорка:** программа не распространяет никакие ассеты EU4. Она только читает файлы из вашей собственной установки игры. EU4 и всё её содержимое — собственность Paradox Interactive. См. [Лицензия](#лицензия).

## Возможности

- **Режимы карты**
  - Провинции — исходная палитра `provinces.bmp`
  - Область / Регион / Суперрегион — стабильные цвета для каждого уровня
  - Режим крепостей — зелёный = крепость, штрихованный зелёный = провинция, покрытая соседней крепостью, синий = вода, чёрный = пустошь, тонкие чёрные границы между провинциями
  - Оптимизация — для работы с оптимизатором крепостей
- **Интерактивный холст** — зум колесом вокруг курсора, панорамирование средней / правой кнопкой мыши, клик по провинции открывает панель информации.
- **Панель провинции** — id, имя, область / регион / суперрегион, наличие крепости, список сухопутных соседей. Провинции-вода и пустоши помечаются соответствующим образом и не имеют ни чекбокса крепости, ни списка соседей.
- **Редактирование крепостей** — чекбокс в панели провинции переключает наличие крепости в `forts.txt`; файл перезаписывается при каждом изменении.
- **Экспорт матрицы соседства** — текстовый файл с группировкой Суперрегион → Регион → Область → Провинция. Пустоши выгружаются как `id : wasteland`.
- **Оптимизация крепостей** — инструмент для нахождения оптимальной схемы расположения крепостей с поддержкой:
  - набора покрываемых провинций (провинции / области / регионы / суперрегионы)
  - обязательных крепостей
  - желательных крепостей (расположение в данных провинциях имеет приоритет при наличии нескольких схем-решений с одинаковым числом крепостей)
  - исключительных провинций для режима *Homebrew*[^1]
  - групповых ограничений (`Group_Name : p1, p2, ... : MinForts`)
  - трёх режимов соседства: **NoAdjacent** / **Homebrew** / **AnyAdjacent**
  - сохранения и загрузки конфигурации в JSON
- **Дерево провинций** — иерархический вид от суперрегиона до провинции; клик по провинции в дереве выделяет провинцию в панели информации.
- **Экспорт в PNG** — сохранить всю карту или только видимую область.
- **Локализация** — изначально доступны русский и английский; любой новый язык добавляется простым добавлением JSON-файла с локализацией в `locales/` (без пересборки).

[^1]: Хоумбрю сабмод для Анбеннара (и, возможно, некоторых других модов) добавляет штраф за наличие фортов в соседних провинциях, за исключением нескольких групп провинций, где для выполнения миссий необходимо иметь форты рядом друг с другом (например, Белые стены Кастанора в моде Анбеннар).

## Отличия от Python-версии

Это полная переработка предыдущего скрипта [EU4-fort-optimizer](https://github.com/Krollbotid/EU4-fort-optimizer).

| Аспект | Python-версия (предыдущая) | C#-версия (этот репозиторий) |
| :--- | :--- | :--- |
| **Ввод данных** | Ручной текстовый файл графа или текстовая область в приложении. | Прямая загрузка `provinces.bmp`, `definition.csv`, `area.txt` и т.д. из папки игры/мода. |
| **Визуализация карты** | Абстрактный граф, отрисовка через `matplotlib` (узлы и рёбра). | Реальная карта провинций EU4, отрисовка через GDI+ с зумом, панорамированием и режимами группировки. |
| **Солвер** | Точная ILP-модель (PuLP) — находит истинное минимальное доминирующее множество для небольших/средних графов. | Жадный алгоритм с прунингом — быстрый на масштабе всей карты (тысячи провинций), но может быть не строго оптимальным. |
| **Соседство** | Берётся из вручную заданных рёбер графа. | Автоматически вычисляется из пиксельного соседства `provinces.bmp` + `adjacencies.csv` (проливы, каналы) + `climate.txt` (пустоши) + `default.map` (вода). |
| **Рабочий процесс** | Абстрактное планирование: построить граф, задать ограничения, решить, проверить. | Визуальное планирование: загрузить карту, кликать по провинциям для информации, смотреть предпросмотры, запустить оптимизатор, экспортировать результат. |
| **Ручная проверка** | Да — проверка любого набора крепостей. | Напрямую нет, но раскраска карты показывает решение. |
| **Экспорт** | JSON-конфигурация. | JSON-конфигурация, матрица соседства (TXT), изображения карты/вида (PNG). |
| **Платформа** | Кроссплатформенная (Python 3.8+). | Windows 10/11 (x64), единый .exe, установка рантайма не требуется. |
| **UI-фреймворк** | `matplotlib` canvas. | Windows Forms. |

*Если вам не нравится эта версия программы, можете использовать её, чтобы для построить матрицу соседства, и далее загрузить её в Python версию.*

## Требования

- Windows 10 или 11 (x64)
- .NET 10 Desktop Runtime *(только для framework-dependent сборки; self-contained сборка через `dotnet publish` не требует ничего)*
- Установленная копия **Europa Universalis IV** или мод с папкой `map/`

## Установка

### Вариант 1 — портативный архив (рекомендуется)

Скачайте архив последнего релиза, распакуйте в любую папку, запустите `EU4FLO.exe`.

```bash
EU4FLO.exe
locales/
├── en.json
└── ru.json
```

Никакого установщика, никакой установки .NET, никаких записей в реестр.

### Вариант 2 — сборка из исходников

Требует предварительной установки .NET 10.0

```bash
git clone https://github.com/Krollbotid/EU4FLO.git
cd EU4FLO
dotnet publish -c Release -o publish
```

В папке `publish` появится единый `EU4FLO.exe` и папка `locales/`.

## Использование

1. Запустите программу.
2. Нажмите **Загрузить папку map/** и укажите папку `map/` из EU4 или мода (например, `…/Europa Universalis IV/common/map` или `…/mod/Anbennar/common/map`).
3. Выберите режим карты на верхней панели.
4. Кликните по провинции, чтобы открыть панель информации.

### Загружаемые файлы

Программа читает из выбранной папки следующие файлы; если чего-то нет, она продолжает работу в урезанном виде.

| Файл                | Назначение                                             |
| ------------------- | --------------------------------------------------     |
| `provinces.bmp`     | сопоставление пикселей и провинций                     |
| `definition.csv`    | id, цвета, имена провинций                             |
| `area.txt`          | провинция → область                                    |
| `region.txt`        | область → регион                                       |
| `superregion.txt`   | регион → суперрегион                                   |
| `default.map`       | списки `sea_starts` и `lakes` (водные провинции)       |
| `climate.txt`       | блок `impassable` (провинции-пустоши)                  |
| `adjacencies.csv`   | морские, канальные и проливные связи между провинциями |
| `forts.txt`[^2]     | по одному id на строку — провинции с крепостью         |

[^2]: Кастомный файл-костыль, содержащий id провинций с крепостью. В будущем планируется добавить альтернативный способ - чтение файлов провинций из папки `history/`

### Экспорт матрицы соседства

Нажмите **Экспорт соседства**, выберите куда сохранить `.txt`. Результат сгруппирован по суперрегионам → регионам → областям, например:

```bash
# bulwar_superregion
    # bahar_region
        # crathanor_area
            516 : 515, 517
            517 : 515, 516, 518, 519
        ...
# (provinces not assigned to any area)
    6749 : wasteland
```

### Оптимизация крепостей

1. Нажмите **Оптимизировать крепости** на верхней панели. Карта переключится в
   режим *Оптимизация*.
2. Заполните поля:
   - **Покрываемые провинции** — по строке на селектор:
     `province, Name_или_ID` · `area, Area_Name` · `region, Region_Name` · `superregion, Superregion_Name`
   - **Обязательные крепости** — id через запятую или пробел
   - **Желательные крепости** — id; используется только как тай-брейкер
   - **Исключительные (homebrew)** — id, которым разрешено стоять рядом с другой крепостью
   - **Группы** — `Group_Name : p1, p2, … : MinForts`
   - **Режим соседства крепостей** — *Запретить соседство*, *Homebrew* или *Разрешить соседство*
3. Кнопка **Показать на карте** под каждым полем подсвечивает соответствующий параметр на карте (не разрушает текущее состояние — предпросмотры накапливаются, запуск оптимизатора их очищает).
4. Нажмите **Запустить оптимизацию**. Результат раскрашивается по роли каждой крепости:

- 🔴 красный = обязательная,
- 🟠 оранжевый = желательная,
- 🟣 фиолетовый = исключительная,
- 💗 розовый = из группы,
- 🟡 жёлтый = обычная.

Провинции без крепости, но соседние с крепостью из решения, получают 🟢 зелёную диагональную штриховку.
5. **Сохранить конфиг** / **Загрузить конфиг** сохраняют всё содержимое формы в JSON.

### Дерево провинций

Нажмите **Дерево провинций** — откроется иерархическое дерево `суперрегион → регион → область → провинция`. Вода и пустоши помечаются суффиксами `[вода]` / `[пустошь]`. Клик по провинции открывает ту же панель информации, что и клик по карте.

### Сохранение изображений

Две кнопки на верхней панели:

- **Сохранить карту (PNG)** — вся отрисованная карта в исходном разрешении.
- **Сохранить вид (PNG)** — только то, что видно на экране в текущий момент (с учётом зума и смещения).

## Добавление нового языка

1. Скопируйте `locales/en.json` в `locales/<код>.json`, например `locales/de.json`.[^3]
2. Измените `_language_name` на `Deutsch` и переведите значения.
3. Перезапустите программу (или просто переключите язык на панели — пересборка не требуется).

Ключи — строки JSON. Если ключ отсутствует в текущем языке, берётся значение из английского, а если нет и там — сам ключ.

[^3]: Немецкий язык

## Возможные проблемы

| Симптом | Решение |
| --- | --- |
| Карта остаётся чёрной после загрузки | `provinces.bmp` и `definition.csv` должны быть из одной версии мода. Устаревший `definition.csv` из ванили и `provinces.bmp` из мода не совпадут. |
| Пустой список соседей у островов | Убедитесь, что `adjacencies.csv` лежит в выбранной папке `map/` и использует `;` как разделитель (парсер принимает `,` как fallback). |
| `forts.txt` не записывается | Папка может быть только для чтения (например, внутри `Program Files`). Переместите мод или саму программу в папку с правами записи. |
| `CS7065: Формат потока значков отличается от ожидаемого` | Присланный `.ico` на самом деле PNG. Пересоберите его как настоящий многоразмерный ICO либо удалите `<ApplicationIcon>` из `.csproj`. |
| Оптимизация идёт долго на большой области покрытия | Ограничьте область покрытия (регион или суперрегион вместо всей карты) — почти мгновенно. |
